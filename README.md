# Binary Conversion Algorithm Analysis

A small Python script that compares the performance of three different algorithms for converting decimal numbers to binary. The script estimates and plots the number of operations each algorithm performs over a range of input values. This is useful for understanding algorithm efficiency and control flow.

## Key Features  
- Implements three distinct decimal-to-binary conversion algorithms.  
- Tracks the number of operations each algorithm performs.  
- Evaluates performance for decimal numbers from 1 to 100.  
- Visualizes the comparative operation count using Matplotlib.

- Python 3.x  
- matplotlib
